# DC7 technology review — 31 October 2026

The repository's installed lock/runtime is Laravel **12.69.3** / PHP **8.3.35**. Authentication is existing JWT plus hashed legacy tokens; no OAuth authorization server, Sanctum or Passport is installed. Database queues, optional Predis/Redis, Reverb, business events, Document Center permissions and the local Python/intelligence interfaces already exist.

| Capability | Classification | Decision |
| --- | --- | --- |
| Existing events, queues, Reverb and permissions | USE NOW WITHOUT UPGRADE | Reused. The existing default worker now also drains `integrations` and `search-index`, after the normal queue. No second worker dashboard or business engine. |
| Semantic/vector search | REIMPLEMENT WITH CURRENT STACK | Versioned local concept vectors in a bounded metadata index, exact precedence and current-source authorization. The provider interface can later delegate to native vector storage or a reviewed local pretrained model. |
| MariaDB native vectors | DEFER UNTIL FRAMEWORK UPGRADE | The local installation is MariaDB 10.4.32. Laravel's current native vector search documents MariaDB 11.7+ or PostgreSQL/pgvector. A database upgrade and populated validation belong in a separate modernization effort; DC7 does not change the database engine. [Laravel search documentation](https://github.com/laravel/docs/blob/13.x/search.md) |
| Laravel AI SDK | DEFER UNTIL FRAMEWORK UPGRADE | Preserve the working provider/tool contracts now; evaluate SDK/package compatibility in a separate lockfile trial. This is a scope decision, not a claim that every AI SDK capability inherently requires Laravel 13. Deterministic business facts remain outside LLM inference. [AI SDK](https://laravel.com/framework/docs/13.x/ai-sdk) |
| Queue routing conveniences | REIMPLEMENT WITH CURRENT STACK | Explicit existing job connection/queue assignments and worker priority configuration provide the needed separation. Laravel 13's routing convenience does not justify an ERP upgrade. [Release notes](https://laravel.com/framework/docs/13.x/releases) |
| Mercure | NOT USEFUL FOR AIMS IN DC7 | It is now an available broadcasting option, but no measured Reverb problem justifies another hub, transport or client migration. Reverb/Echo and the bounded fallback remain. [Broadcasting](https://laravel.com/framework/docs/13.x/broadcasting) |
| Framework security improvements | DEFER UNTIL FRAMEWORK UPGRADE | Laravel 13 adds origin-aware request-forgery improvements and requires PHP 8.3. Continue current token/tenant/permission protections and plan a separate dependency/upgrade test. Laravel 12 remains in its published security-support window through 24 February 2027; no claim of indefinite support. [Support policy](https://laravel.com/framework/docs/13.x/releases), [upgrade guide](https://laravel.com/framework/docs/13.x/upgrade) |
| MCP | REIMPLEMENT WITH CURRENT STACK | A controlled stdio adapter reuses shared AIMS reads; no additional framework package is needed. Uses the implemented 2025-11-25 and 2025-06-18 revisions, with one supported-version definition. Remote OAuth/HTTP support is explicitly deferred. [Current MCP versioning](https://modelcontextprotocol.io/specification/2025-11-25/basic/versioning), [stdio](https://modelcontextprotocol.io/specification/2025-11-25/basic/transports) |
| Observability | USE NOW WITHOUT UPGRADE | Local technical spans, W3C IDs and OTLP JSON export use open representations. A collector/backend is optional. This is compatible tracing/export, not an assertion that the full OpenTelemetry SDK or all automatic instrumentation is installed. [OTLP](https://opentelemetry.io/docs/specs/otlp/) |

The next modernization review should cover the framework/security horizon, newer MariaDB support, dependency constraints and populated upgrade/rollback evidence. It is not started automatically.
