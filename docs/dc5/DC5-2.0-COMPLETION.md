Historical receipts without cargo links, unverified loaded quantities and variable units without base measurements cannot support exact transit promises. The new seven-day assistant supply preview is bounded and starts with dated open POs; it is not a complete undated/standalone cargo register. ETA is an estimate requiring receipt, inspection and any putaway; port arrival is not confirmed warehouse availability.

Reservations have no invented unattended expiry rule. Invalid lot reservations are surfaced for authorized release/reallocation; confirmed order changes retain source history. Cycle counts still require explicit scope and approval; automatic ABC/recurring count policy and broader statistical anomaly scoring were not introduced. New issue rules require explicit configuration. Devices/cameras, external tracking, degraded-network multi-user Reverb and real-site workload capacity need site validation. No new vertical, multi-master offline sync, automatic transfers or DC6 was started.
