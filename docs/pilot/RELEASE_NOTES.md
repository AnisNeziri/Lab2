# AIMS 1.1.2-rc.1 — pilot preparation

For pilot users:

- Report a problem from your workspace. AIMS includes the page, role and release; optional notes should contain no customer details, account numbers or passwords.
- Record actual workflow trials and source documents. Independent review keeps opening balances and restore claims traceable.
- Owners can prepare a phased rollout, review data gaps, triage feedback and save daily/weekly reviews. Unknown days and unqualified forecasts are clearly shown.
- If a production request fails, give support the AIMS reference shown with the error.

Për përdoruesit e pilotit:

- Raporto një problem nga hapësira e punës. AIMS përfshin faqen, rolin dhe versionin; shënimet opsionale nuk duhet të përmbajnë të dhëna klientësh, numra llogarish apo fjalëkalime.
- Regjistro provat reale dhe dokumentet burimore. Shqyrtimi i pavarur ruan gjurmueshmërinë e bilanceve fillestare dhe provave të rikthimit.
- Pronarët mund të përgatisin aktivizimin gradual, të shqyrtojnë boshllëqet, të klasifikojnë problemet dhe të ruajnë shqyrtime ditore/javore. Ditët e panjohura dhe parashikimet e pakualifikuara tregohen qartë.
- Kur një kërkesë në prodhim dështon, jepi mbështetjes referencën AIMS që shfaqet me gabimin.

This is an unmerged, uncertified candidate until release checks and installation review pass. The real pilot has not started. Existing passwords, data, permissions, personalized workspaces and the original checkout are preserved. Take and verify the selected installation's full backup before applying its migration.
